# Template provenance

Adapted from the base UI template (`vinext-starter`).

The UI catalog, hooks, utilities, Tailwind stylesheet and vendored Shadcn CSS originate from that template. The vendored CSS license is preserved beside the file. Dependencies retain their own licenses.

CampusFlow uses Vite to build a browser demo and to run the local SQLite and SMTP services. Upstream hosting and authentication configurations are not included.
